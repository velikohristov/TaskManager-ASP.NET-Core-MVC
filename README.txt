Проект "Task Manager"

1. За проекта.

Task Manager е уеб приложение за управление на ежедневни задачи, разработено с ASP.NET Core MVC.

Приложението позволява на потребителите да създават, преглеждат, редактират и изтриват задачи, както и да ги организират по категории и приоритети.

Целта на проекта е да предостави лесен и удобен начин за организиране на ежедневните ангажименти.

2. Основни функционалности.

- Създаване на нови задачи.
- Преглеждане на всички задачи.
- Редактиране на съществуващи задачи.
- Изтриване на задачи.
- Отбелязване на задачите като изпълнени.
- Задаване на срок за изпълнение.
- Организиране на задачите по категории.
- Определяне на приоритет на всяка задача.
- Създаване, редактиране и преглеждане на категории и приоритети.
- Валидация на въведените данни.

3. Използвани технологии.

- C#
- ASP.NET Core MVC (.NET 8)
- Entity Framework Core
- Microsoft SQL Server LocalDB
- Razor Views
- HTML
- CSS
- Bootstrap
- JavaScript.

4. Структура на проекта.

Проектът използва MVC архитектура и включва следните основни компоненти:

- Models – модели за задачи, категории и приоритети.
- Controllers – контролери за управление на данните.
- Views – потребителски изгледи.
- Data – контекст за връзка с базата данни.
- wwwroot – статични файлове и ресурси.

5. Изисквания за стартиране.

За стартиране на проекта са необходими:

- Инсталиран .NET 8 SDK.
- Visual Studio с ASP.NET и web development компонентите.
- SQL Server Express LocalDB.
- Entity Framework Core Tools.

6. Конфигурация на базата данни.

Проектът използва SQL Server LocalDB.

Връзката към базата данни е конфигурирана в `appsettings.json` чрез Connection String с име `DefaultConnection`.

Името на базата данни е `TaskManagerDb `.

Използва се Windows Authentication (`Trusted_Connection=True`), поради което не е необходимо въвеждане на отделно потребителско име и парола за локалната конфигурация.

7. Инсталиране и стартиране.

1. Клонирай GitHub хранилището.
2. Отвори проекта във Visual Studio.
3. Възстанови NuGet пакетите.
4. Провери настройките за връзка с базата данни.
5. Отвори Package Manager Console и изпълни:

`Update-Database` .

6. Стартирай проекта чрез Visual Studio или командата:

`dotnet run` .
